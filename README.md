# quecomemos-web

Páginas públicas de la app **¿Qué comemos?**, servidas con GitHub Pages:

- `invite/`: el enlace de invitación a una lista de la compra compartida (abre la app con el código puesto).
- `privacy/`: la política de privacidad.

La fuente está en el repositorio de la app (`site/`); este repositorio solo las publica.
